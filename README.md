# NEXT-JS-FOUNDAMENTALS-PROJECTS

This repository contains a collection of Next.js projects, each focusing on different aspects and features of the Next.js framework. Whether you're exploring file-based routing, authentication, or building a food-related application, you'll find examples and code snippets that demonstrate how to use Next.js effectively.

## Projects Included

### 1. `next-event-file-based-routing-pages`

This project demonstrates how to implement file-based routing in Next.js. It covers the basics of dynamic routes, nested routes, and route parameters, helping you understand how Next.js handles navigation and page management. Alos working the pre rendereing, ISR, api, and communictating with data base as well.

### Note for `next-event-file-based-routing-pages`:

add env.local file to the root directory and the value of the following variable.

```bash
NEXT_FIREBASE_URL = your fire base varible
DB_URL = mongo db url.

```

### 2. `next-level-food`

A food-related application built with Next.js. This project explores building dynamic pages, server-side rendering, and integrating APIs for data fetching. It's perfect for learning how to build a scalable, production-ready food website using modern web technologies.

### 3. `next-news`

In this project, you'll learn how to build a news application using Next.js. The focus is on fetching data from external APIs, handling server-side rendering (SSR), and optimizing performance for fast page loads.

### 4. `next-post-application`

This project is a blog-like application that explores content management with Next.js. It demonstrates how to create, read, update, and delete (CRUD) operations in a full-stack environment using Next.js and various backend technologies.

### 5. `nextjs-authentication`

Authentication is a critical aspect of modern web applications. This project shows how to implement authentication in Next.js, covering both client-side and server-side authentication flows, including protected routes and session management.

### 6. `user-authentication`

A similar project to `nextjs-authentication`, but with a different approach or set of features. This project may focus on advanced authentication techniques, such as OAuth, JWT, or integrating with third-party authentication providers.

## Getting Started

To get started with any of these projects:

1. Clone the repository:

   ```bash
   git clone https://github.com/UzairKhan313/Next-js-foundamental-projects.git
   ```

2. Navigate to the interested project diricetory:

   ```bash
   cd <intereste dircotory>
   ```

3. Install the core dependices:

   ```bash
   npm install
   ```

4. Run the Development Server:
   ```bash
   npm run dev
   ```
